# Free Professional CV Builder أداة احترافية لإنشاء السيرة الذاتية - ثنائية اللغة (عربي / إنجليزي). A professional CV builder tool - bilingual (Arabic / English). --- ## ✨ المميزات | Features - 🌐 **ثنائي اللغة** - تبديل فوري بين العربي والإنجليزي - 💾 **حفظ وتحميل** - احفظ بياناتك كملف JSON وحمّلها لاحقاً - 📄 **تنزيل PDF** - بضغطة زر - 🔄 **حفظ تلقائي** - في المتصفح (localStorage) - 📱 **يعمل على الجوال** - تصميم متجاوب - 🎨 **معاينة لحظية** - شاهد التغييرات مباشرة --- ## 🚀 كيف ترفعه على GitHub Pages ### الطريقة 1: من الموقع مباشرة 1. روح على [github.com](https://github.com) وسجّل دخول 2. اضغط على **+** فوق ثم اختر **New repository** 3. سمّ المستودع باسم مثل `cv` أو `my-cv` 4. اختر **Public** (مهم للنشر المجاني) 5. علّم على ✅ **Add a README file** 6. اضغط **Create repository** 7. اضغط على **Add file** ← **Upload files** 8. ارفع ملف `index.html` 9. اضغط **Commit changes** ### تفعيل GitHub Pages 1. روح على **Settings** (في المستودع نفسه) 2. من القائمة اليسار اضغط **Pages** 3. تحت **Source** اختر **Deploy from a branch** 4. اختر **main** و **/ (root)** ← اضغط **Save** 5. انتظر دقيقة، الموقع راح يطلع لك على رابط مثل: ``` https://YOUR_USERNAME.github.io/cv/ ``` --- ## 🔧 تخصيص الموقع افتح `index.html` بأي محرر نصوص: ### تغيير الاسم في ترويسة الأداة - ابحث عن `Sultan` وغيّره لاسمك - ابحث عن `class="brand-logo">S<` وغيّر الحرف ### تغيير الألوان في بداية ملف CSS داخل `
